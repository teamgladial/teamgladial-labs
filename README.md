# Gladial Labs

A static Astro project exhibit for experiments, prototypes, demos, and open-source work under the Gladial umbrella. Add project data in `src/pages/index.astro` as projects are ready to feature.

## Local development

```sh
npm install
npm run dev
```

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`
- Node.js: `>=22.12.0`

This is a static Astro site; no Cloudflare adapter or server runtime is required.
